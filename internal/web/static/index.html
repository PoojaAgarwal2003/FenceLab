READ THE FINE PRINT

A model. Not a cluster.

What we check

No stale writes: a superseded attempt must not commit. One logical effect: retries must not repeat an already committed effect.

What we assume

One authoritative scheduler, virtual time, and atomic storage operations. Storage acknowledges a new fence before dispatch. Durability is assumed, not implemented.

What this isn't

Milestones 1–3 are local models. v2 explores equal-time deliveries within a fixed two-attempt scenario, not arbitrary failures. Durable recovery, real processes, and scheduler workloads remain future work.
